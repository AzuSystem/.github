## 👀 What does AzuOS offer?
AzuOS offers Azura, a Desktop Environment built from the ground up with [Qt](https://en.wikipedia.org/wiki/Qt_(software)) and [Freya ( Skia )](https://freyaui.dev).
It offers an almost unreal design almost only ever seen in concept designs.

## 🧐 Why?
The project provides a very curated user experience with how it is designed to be used and interacted with. The customisation features are intentionally limiting, to not stray far from the intentional design. There is no real reason to use AzuOS or its desktop environment beyond its aesthetics and your experience using it.
tl;dr it looks awesome stuff, but also why not~

## 🔧 What does AzuOS run on?
AzuOS is built on-top of Debian Trixie.
Azura and its related components are built with the [Qt Framework](https://en.wikipedia.org/wiki/Qt_(software)) under [Rust](https://rust-lang.org), with a few programs built with [Freya](https://freyaui.dev) which uses [Skia](https://skia.org) underneath.
